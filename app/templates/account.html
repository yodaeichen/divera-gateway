Als App auf dem Handy

Installiert Du benutzt das Gateway gerade als App.

Die Installation als App geht nur, wenn das Gateway über HTTPS geöffnet ist (Adresse beginnt mit https://).

Das Gateway lässt sich wie eine App auf diesem Gerät installieren: eigenes Symbol, eigenes Fenster, keine Adresszeile.

So kommt das Gateway auf den Home-Bildschirm von iPhone oder iPad:

  1. Diese Seite in Safari öffnen.
  2. Unten auf Teilen tippen (Quadrat mit Pfeil nach oben).
  3. Zum Home-Bildschirm wählen und bestätigen.
  4. Das Gateway über das neue Symbol öffnen und hier Push-Meldungen einschalten.

So kommt das Gateway als App auf dieses Gerät:

  1. Android (Chrome): Menü mit den drei Punkten, dann „App installieren" oder „Zum Startbildschirm hinzufügen".
  2. Rechner (Chrome, Edge): Symbol „Installieren" rechts in der Adresszeile.
